The instance settings move to an admin dashboard (`/dashboard/admin/`): Workspaces, Media and OAuth apps leave the workspace sidebar, and instance admins reach them from an **Admin dashboard** link at the bottom of it, with a link back to the workspace. Anyone else who opens an admin page is sent back to their workspace. Old links (`/dashboard/media`, `/dashboard/apps`, `/dashboard/workspaces`) still work.

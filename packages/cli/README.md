# bongsu

The command line for [Bongsu](https://github.com/NYT87/bongsu), a self-hosted publishing scheduler for Instagram and
YouTube Shorts comments. It is for what is better scripted than clicked: the queue, texts, approvals from a terminal,
stats, exports, the Cloudflare secrets, and a local MCP bridge for agents. It talks to your instance's HTTP API only.

```sh
npx bongsu login --url https://bongsu.example.com
npx bongsu queue
npx bongsu --help
```

Node 22 or later. The guide: [the command line](https://github.com/NYT87/bongsu/blob/main/site/docs/cli.md).
